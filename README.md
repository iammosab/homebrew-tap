# iammosab/tap

Homebrew formulae for my projects.

```bash
brew install iammosab/tap/wingbar
brew services start wingbar
```

| Formula | What it is |
| --- | --- |
| [wingbar](https://github.com/iammosab/wingbar) | A light native macOS status bar: workspaces and script widgets in two wings |

`Formula/wingbar.rb` is updated automatically by wingbar's release workflow.
